WOLFICH · Автопоход — программа для Windows
===========================================
Совместима только с эмулятором LDPlayer 9.

Установка (один раз)
1. Распакуйте архив в любую папку (например, C:\WOLFICH). Запускать прямо из архива нельзя.
2. Запустите SETUP.bat — он скачает Electron с GitHub (около 110 МБ), соберёт WOLFICH.exe
   и положит ярлык WOLFICH на рабочий стол.

Обновление: распакуйте новый архив поверх старой папки (с заменой файлов) и запустите SETUP.bat —
скачивать заново ничего не придётся.

Запуск
1. Запустите WOLFICH (ярлык на рабочем столе или WOLFICH.exe в папке).
   Если Windows покажет «Система Windows защитила ваш компьютер» —
   нажмите «Подробнее» → «Выполнить в любом случае» (программа не подписана сертификатом).
   То же может случиться с SETUP.bat.
2. Введите ключ доступа (один раз — программа его запомнит).
3. Настройте LDPlayer и подключите его по «Руководству: LDPlayer» внизу окна программы.
4. Укажите, сколько маршей держать на каждом ресурсе, и нажмите «Старт».

Язык: переключатель RU / EN в правом верхнем углу окна.
Модуль бота программа берёт свежим с сайта при каждом запуске,
поэтому исправления бота приходят без новой программы. Без интернета — встроенная копия.
