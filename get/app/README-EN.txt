WOLFICH · Auto-Gather — program for Windows
============================================
Compatible with the LDPlayer 9 emulator only.

Installation (once)
1. Unpack the archive into any folder (e.g. C:\WOLFICH). Don't run it straight from the archive.
2. Run SETUP.bat — it downloads Electron from GitHub (about 110 MB), builds WOLFICH.exe
   and puts a WOLFICH shortcut on the desktop.

Update: unpack the new archive over the old folder (replacing files) and run SETUP.bat —
nothing has to be downloaded again.

Running
1. Start WOLFICH (desktop shortcut or WOLFICH.exe in the folder).
   If Windows shows "Windows protected your PC" — click "More info" → "Run anyway"
   (the program isn't signed with a certificate). The same may happen with SETUP.bat.
2. Enter your access key (once — the program remembers it).
3. Set up and connect LDPlayer following the "Guide: LDPlayer" at the bottom of the program window.
4. Set how many marches to keep on each resource and click "Start".

Language: the RU / EN switch is in the top-right corner of the window.
The bot module is downloaded fresh from the site on every start, so bot fixes arrive
without a new program. Without internet the built-in copy is used.
